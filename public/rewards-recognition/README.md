# Rewards and Recognition Proposal

A lesson-by-lesson recognition prototype for St Peter’s classroom teachers, prepared for feedback from Heads of Faculty and pastoral leaders.

All students and records are fictional. Changes are saved in each browser only. Digital Achievements recognise contributions, while Recognition Levels begin at 100 lifetime points, then 250, 500 and 1,000. This is a proposal before working-party development, testing and any later small trial.

Open `index.html` through GitHub Pages or a local static server.
