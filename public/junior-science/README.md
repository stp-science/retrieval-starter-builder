# Junior Science Student Retrieval Practice

Published copy of St Peter's School Junior Science Retrieval Practice, originally at https://year7-cells-retrieval.talbotino.chatgpt.site.

This is the student app. It preserves the original questions, year and topic choices, answer reveal, self-marking and spaced review. Progress is saved in the browser on each device; the GitHub copy starts with its own progress.

The original app and question banks are unchanged. The GitHub build uses Vite to serve the React app as static files with relative asset URLs.

To rebuild: extract student-practice-source.zip, run `npm install`, then `npm run build`. The result is in `github-dist/`.
